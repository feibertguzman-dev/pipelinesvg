Etapa 1: CI Build & Test

Fase de saneamiento inicial. El código fuente se transforma en binario verificable.

> mvn clean install jacoco:report
  • Aislamiento: Uso de Mocks para DBs.
  • Fail Fast: Fallo inmediato si Test < 85%.

Etapa 2: Quality Gate

Auditoría estricta automatizada. Se busca deuda técnica y vulnerabilidades.

-Dsonar.qualitygate.wait=true
  • Bloqueante: 0 Bugs Críticos permitidos.
  • Copy/Paste: Prohibido > 3% duplicidad.

Etapa 3: Docker Packaging

Empaquetado inmutable. Lo que se prueba aquí es idéntico a lo que va a Producción.

docker build -t app:$SHA .
  • Multi-Stage: Imagen final de solo 150MB.
  • Trazabilidad: Tagged con Git SHA.

Etapa 4: Canary Release

Despliegue progresivo. Si las métricas fallan, el sistema se revierte solo.

kubectl get rollouts
  • Paso 1: 5% Tráfico a nueva versión.
  • Paso 2: Monitoreo automático (2 min).
  • Paso 3: Rollout 100% o Rollback.
